# VIP tattoo school — Session Handoff

Розгорнутий підсумок усієї роботи над лендингом "VIP tattoo school" у цьому сеансі. Признач як контекст для нового сеансу, щоб продовжити верстку без втрати деталей.

## Репозиторій і файли

- Репозиторій: `kossbarss/-`
- Гілка: `tattoo-school-landing`
- Файли:
  - `/workspace/-/index.html` — головна сторінка, російська (за замовчуванням)
  - `/workspace/-/ua/index.html` — українська версія (той самий контент, перекладений)
  - `/workspace/-/style.css` — **спільний** для RU і UA
  - `/workspace/-/script.js` — JS для RU-сторінки
  - `/workspace/-/ua/script.js` — JS для UA-сторінки (окремий файл, зміни треба дублювати вручну!)
  - `/workspace/-/assets/` — зображення (логотипи, фото Вікторії тощо)

## Технічні обмеження (важливо!)

- **Тільки чистий HTML/CSS/JS.** Жодного React, Tailwind, TypeScript, shadcn, білд-процесу, `node_modules`. Це свідомий вибір із самого початку — сайт має бути легким і його можна вставити один-в-один у WordPress/Elementor.
- Коли надають React/Tailwind/shadcn код "для інтеграції" — **не встановлювати ці технології**. Натомість переносити візуальну механіку (кольори, позиціонування, анімацію) вручну в наш CSS/HTML, перефарбовану в наші кольори.
- Кожна зміна тексту/стилю має бути **однакова і в RU, і в UA** версії (з відповідним перекладом).

## Бренд і дизайн-система

- Назва бренду: **"VIP tattoo school"** (VIP — великими, решта — маленькими).
- CSS-змінні (кольори): `--ink` (#15110f), `--ink-soft`, `--paper`, `--paper-alt`, `--white`, `--muted` (#6f645c), `--gold` (#c9a24a), `--gold-light` (#e8d5a8), `--gold-dark` (#a9803a), `--blood` (#a3162e), `--blood-dark` (#7a0f22), `--blood-light` (#c94257), `--border` (rgba(21,17,15,0.12))
- Шрифти: `--font-display` (Bebas Neue), `--font-accent` (Playfair Display italic), `--font-body` (Inter), `--font-rise` (Space Grotesk), `--font-sticky` (Poppins), `--font-hero` (Instrument Serif — для заголовку hero)
- Більшість секцій сайту — світла кремова палітра (ink/gold/blood на `--paper`). **Виняток: hero-блок тепер темний** (майже чорний фон) — див. нижче.

## Робочий процес для КОЖНОЇ зміни (стандартний цикл)

1. Редагувати `index.html`, `ua/index.html`, `style.css` — дзеркально для обох мов.
2. Локальний сервер для перевірки: `cd /workspace/- && python3 -m http.server 5199`
3. Перевірка через Playwright-скріншоти: desktop (1280px) і mobile (~412px), і RU, і UA — усі 4 комбінації.
4. `git add -A && git commit -m "..." && git push -u origin tattoo-school-landing`
5. Перебудувати самодостатнє HTML-прев'ю (інлайнить усі `assets/*` як base64, підставляє `style.css`/`script.js`/`particles.js` інлайн) — скрипт `build_preview.py` (динамічно знаходить усі `assets/*.{png,jpg,jpeg}` через regex, без хардкоду).
6. Опублікувати прев'ю через `Artifact` tool на **постійний URL**: `https://claude.ai/code/artifact/d6368eb0-dab4-4868-b95a-4c65b113e57f` (кожен раз редеплоїти на той самий URL, не створювати новий).
7. Відповідати користувачу **українською**.

## Хронологія роботи в цьому сеансі (від початку до кінця)

### 1. Мовний перемикач (RU/UA)
Реалізовано bouncy sliding-thumb перемикач мови на основі наданого React-компонента — портовано в чистий CSS/JS, без React.

### 2. Огляд React "responsive-hero-banner" (Mars-тема)
Користувач надав React-компонент (тема Марс: navbar, badge, hero headline, CTA-кнопки, partners row) з інструкцією "інтегрувати через shadcn/Tailwind/TypeScript". Пояснено, чому буквальна інтеграція React/Tailwind неможлива (порушує архітектуру статичного сайту) — і що натомість візуальні елементи переносяться вручну.

Затверджені 5 пунктів (дослівно від користувача):
1. Взяти лише колірне насичення та візуальне позиціонування навігації → реалізовано як скляна напівпрозора навігація (`.header .container`: `background: rgba(21,17,15,0.78); backdrop-filter: blur(24px) saturate(1.4);`)
2. Full-bleed фонове фото — мобільна версія без змін, десктоп отримує накладене фото → пізніше повністю замінено на вирізаний портрет (без фону)
3. "Партнери" внизу hero → замінено на 5 тегів: "ТОП-техники", "Видео-уроки", "Инструменты", "Модели продаж", "Монетизация навыков"
4. Контент переписано під тату-тематику, використовуючи шрифти з референсу (додано Instrument Serif)
5. Кольори наші (ink/gold/blood) + реальне фото засновниці

### 3. Фото засновниці (Вікторія) — сага з вирізанням фону
- Спроба через `rembg` — **заблоковано мережевою політикою** (403 на github.com/danielgatis/rembg), не обходили обмеження.
- Вирішено через `mediapipe==0.10.9` (стара версія з вбудованою моделлю в pip-пакеті, без завантаження з мережі) + `scipy.ndimage` для очищення маски (залишити лише найбільший зв'язний компонент, виключити артефакти стільця).
- Результат мав дрібний артефакт (кут стільця) — користувач пізніше надав **вже чисто вирізане фото** (`assets/founder-photo.png`, 1074×1708 PNG з прозорим фоном), яким і замінили попередню версію.
- Фото розміщено як `<div class="hero-founder-photo"><img></div>` між підзаголовком і системним текстом.

### 4. Видалення декоративного SVG-блоку
Темна квадратна картка з SVG-ілюстрацією (лінійна графіка + "Пошаговая система от эскиза..." бейдж) видалена повністю з hero — користувач вказав "цей елемент не потрібен взагалі". `.hero-inner` grid змінено з 2 колонок на 1 (потім знову на 2 — див. нижче).

### 5. Типографічні й контентні правки (по черзі, кожна з мгновенною перевіркою):
- "с нуля до первых клиентов" → "с нуля до постоянных клиентов" (тільки ці слова, решта тексту не торкались)
- Розширено абзац "Пошаговая система..." (додано "11+ странах мира")
- `.hero-kicker` зроблено легшим (font-weight 700→400, пізніше повністю перероблено в бейдж-пігулку)
- Виправлено відступи між заголовком/підзаголовком/кікером окремо для десктопу і мобільної версії (вимірювалось пікселями з референс-скріншотів)
- `.hero-lede` (системний текст) забарвлено градієнтом blood→gold через `background-clip: text`, потім (після переходу на темний фон) — gold-light→gold

### 6. Порівняння з референсом mktarget.weblium.site (курс по таргету, Марина Коваленко)
Користувач надав скріншоти оригінального лендингу і .mht файл. Детально проаналізовано і скопійовано:
- **Вирівнювання по центру**: заголовок, підзаголовок, фото, системний текст, теги — всі по центру колонки; лишень **кікер залишився зліва** (як в референсі)
- **Позиціонування price-box**: переставлено з окремого блоку під hero у **другу колонку grid** (`.hero-inner` знову 2 колонки: `1.05fr 0.95fr` на десктопі, 1 колонка на мобільній)
- Видалено кнопку "Забрать курс со скидкой" з ряду CTA (залишили тільки в price-box, щоб не дублювати)

### 7. Бейдж-пігулка (кікер)
`.hero-kicker` перероблено з простого italic-тексту на бейдж-пігулку (rounded-full, border, напівпрозорий фон) з текстом "Онлайн-курс от ТОПового тату-мастера и основателя школы для мастеров тату индустрии 2026" (додано рік).

### 8. Повний редизайн hero в темний варіант (за референсом Mars-компонента)
- Фон hero: світлий кремовий → **темний градієнт** (`#0e0a08` → `#1c140f`)
- Усі кольори тексту в hero перефарбовано під темний фон (заголовок білий, підзаголовок світло-сірий, бейдж напівпрозорий світлий, price-box темна картка з золотою рамкою)
- Додано **світлову дугу** (`.hero-arc`, gradient ring blood/gold) — **пізніше повністю видалено** за проханням користувача ("некоректно виглядає")
- Додано ряд з двома CTA-кнопками (primary + secondary) — **primary кнопку пізніше видалено** (дублювала price-box), залишилась тільки secondary "Смотреть программу"
- Додано stagger fade-slide-in анімацію появи для всіх елементів hero (`@keyframes heroFadeSlideIn`)
- Теги (`.hero-tags`) залишились тими самими 5 словами, тільки перефарбовані під темний фон

### 9. Точкові правки після редизайну
- `.hero h1 em` кольор: blood-light → **gold-light** (потім змінено на градієнт gold-light→gold, ідентичний `.hero-lede`, щоб текст "с нуля до постоянных клиентов" збігався кольором з "Пошаговая система...")
- Видалено кнопку "Забрать курс со скидкой" з hero-cta-row (залишили тільки "Смотреть программу")
- Видалено світлову дугу (`.hero-arc`) повністю
- Видалено посилання "курс прошли 300+ учеников →" повністю (з HTML і з CSS-анімацій)
- Текст підзаголовка: "...без страха испортить кожу" → "...без страха испортить **рисунок на коже**" (і UA: "...зіпсувати **малюнок на шкірі**")

### 10. Накладання тексту на фото (1:1 з референсу)
За детальним аналізом референс-скріншоту (де текст "Пошаговая система..." накладається на низ фото моделі) — реалізовано:
- `.hero-lede` отримав `margin-top: -85px` (мобільна) / `-95px` (десктоп, `@media min-width:901px`), що дає **точно ~15% overlap** з фото (виміряно через Playwright: `imgRect.bottom - ledeRect.top) / imgRect.height`)
- `.hero-lede` отримав `position: relative; z-index: 2`, щоб текст малювався НАД фото

### 11. Затемнення фото (додано, потім скасовано)
- Спроба додати `.hero-founder-photo-shade` (градієнтний div з `rgba(0,0,0,0.2)`) для затемнення низу фото під текстом — **користувач сказав "виглядає некоректно"**
- **Повністю видалено**: і div з HTML (`index.html`, `ua/index.html`), і CSS-правило `.hero-founder-photo-shade` та відповідний media-query рядок. Фото зараз **без** будь-якого додаткового затемнення, текст просто накладається на 15% без темного градієнта.

## Відомі відкриті питання / можливі наступні кроки

- Користувач порівнював наш лендинг із референсом mktarget.weblium.site покроково (елемент за елементом) — можливо, залишились ще неперенесені деталі з цього референсу нижче hero-блоку (у секціях "Тебе подойдёт курс" тощо), якщо користувач продовжить порівняння.
- Прев'ю-скрипт `build_preview.py` (у scratchpad, не в репо) треба відновити в новому сеансі, якщо знадобиться — він динамічно інлайнить усі `assets/*` файли, тож новий сеанс може просто написати аналогічний скрипт заново (проста Python-заготовка: regex по `assets/[\w.\-]+\.(?:png|jpg|jpeg)`, base64-інлайн, підстановка `style.css`/`script.js`/`particles.js` як `<style>`/`<script>`).
